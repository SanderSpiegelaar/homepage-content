## MODIFIED Requirements

### Requirement: Current destination feedback
The primary navigation SHALL include the Exa Research destination and SHALL visually and programmatically identify the active destination.

#### Scenario: Active dashboard destination
- **WHEN** the user is viewing the root dashboard route
- **THEN** the dashboard navigation item is presented as the current destination

#### Scenario: Active Exa Research destination
- **WHEN** the user is viewing the Exa Research route
- **THEN** the Exa Research navigation item is presented as the current destination
